# 版本与内容说明

本仓库包含 17 篇 Go 学习笔记、独立示例和配套工程。

## 内容范围

- `01`—`17`：按课程顺序编号的 17 篇 Markdown 笔记。
- `examples/`：可独立运行的 Go 示例及其 `go.mod`。
- `code/`：开发环境、综合项目和性能分析实验工程。

## 版本约定

- 建议工具链：Go 1.27.3 或更新的兼容版本。
- 示例模块的 `go` 指令统一使用 `1.27.0`。
- 正文中出现的其他 Go 版本号用于解释历史语言变化、运行时实现或第三方依赖要求，不代表整套笔记采用不同的基础工具链。
- 阅读运行时源码时，应以对应章节标明的 Go 版本为准；语言规范保证与特定版本的实现细节分开理解。

## 文件组织

笔记与配套源码之间使用相对路径引用。移动文件时应保持 `examples/`、`code/` 与 Markdown 文件之间的相对结构。

## 仓库清理范围

仓库仅保留学习内容和可复现所需的源文件。机器相关的 profile、trace 二进制、临时日志、内部核验报告、校验清单和生成过程元数据不纳入版本控制；性能实验可按正文命令在本地重新生成采样文件。
