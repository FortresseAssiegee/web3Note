## 环境要求

- 建议使用 Go 1.27.3 或更新的兼容工具链。
- 示例模块的 `go.mod` 使用 `go 1.27.0` 作为语言版本声明。
- 第三方依赖由各示例目录中的 `go.mod` 管理。
- 需要 PostgreSQL、Redis、Doris 或监控服务的内容，按对应章节准备外部服务；没有外部依赖的示例可以独立运行。

## 运行示例

仓库中包含多个相互独立的 Go module，不应在仓库根目录统一执行 `go run .`。

进入具体示例或工程目录后运行，例如：

```bash
cd examples/environment/ENV-01
go run .
```

运行完整工程前，先阅读对应章节中的配置和启动步骤。项目和实验工程的入口分别位于 `code/project/`、`code/environment/` 和 `code/performance/`。


## 版本控制说明

- 仓库保留学习所需的 Markdown、SVG、Go 源码、测试、模块文件及本地模块代理样例。

- `.gitignore` 已忽略常见构建产物、性能采样文件、环境变量文件和 IDE 文件。
